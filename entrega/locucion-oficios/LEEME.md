# Locución de los oficios: propuesta (sin grabar)

Voz: **Nico**, la narradora del juego (la de los avisos de Otsagabia). Una toma por frase, en castellano.

## El herrero (Lesaka), unos 820 créditos

| Momento | Frase |
|---|---|
| El taller entero | En las ferrerías del Bidasoa se trabajaba el hierro con la fuerza del agua: el río movía los fuelles y un gran mazo. En cada pueblo, el herrero hacía herraduras, clavos, rejas de arado y herramientas. |
| Herramienta | Fragua. El fuego de carbón donde se calienta el hierro. |
| Herramienta | Fuelle. Sopla aire para avivar el fuego. |
| Herramienta | Yunque. El bloque de hierro sobre el que se golpea. |
| Herramienta | Martillo. Para dar forma al hierro caliente. |
| Herramienta | Tenazas. Para sujetar el hierro sin quemarse. |
| Paso 1 | El hierro sale de la fragua tan caliente que brilla. ¿Con qué sujeta el herrero el hierro al rojo? |
| Paso 2 | Con el fuelle se sopla aire al carbón hasta que el hierro se pone naranja, al rojo vivo; entonces se golpea en el yunque para darle forma de herradura. Frío no se deja trabajar, y si se pone blanco se quema. |
| Paso 3 | Al final se mete en agua fría: ¡ssshhh! Así el hierro se enfría y queda duro. |

## La panadera (Artajona), unos 550 créditos

| Momento | Frase |
|---|---|
| El taller entero | Antes, cada familia amasaba su pan en casa una vez por semana y lo cocía en el horno de leña del pueblo. Para no confundirlos, cada casa marcaba sus panes con su propia señal. |
| Herramienta | Artesa. El cajón de madera donde se amasa. |
| Herramienta | Levadura madre. Un trozo de masa guardado de la vez anterior. |
| Herramienta | Horno de leña. Se calienta con leña o sarmientos. |
| Herramienta | Pala. Para meter y sacar el pan. |
| Paso 1 | Harina, agua, sal y levadura madre: se amasa con fuerza. |
| Paso 2 | Se deja la masa tapada unas horas. ¿Por qué se hincha la masa? |
| Paso 3 | Con la pala se meten los panes en el horno caliente, sin quemarse. |

## El cantero (Puente la Reina), unos 650 créditos

| Momento | Frase |
|---|---|
| El taller entero | Los canteros sacaban la piedra de la cantera y la tallaban en bloques perfectos llamados sillares. Con ellos se levantaron puentes, iglesias y palacios, como el puente de Puente la Reina. |
| Herramienta | Escuadra. Para que los ángulos queden rectos. |
| Herramienta | Cincel. Para tallar con precisión. |
| Herramienta | Maza. Para golpear el cincel. |
| Herramienta | Pico. Para quitar la piedra que sobra. |
| Paso 1 | No todas las piedras sirven: una grieta y el sillar se rompe. ¿Qué piedra elige el cantero? |
| Paso 2 | Primero se quita a golpes la piedra que sobra. |
| Paso 3 | Después se alisan las caras con el cincel, comprobando con la escuadra que todo quede recto. |
| Paso 4 | Cada cantero grababa su marca en los sillares que hacía: así le pagaban por cada piedra. |

## El tonelero (Viana), unos 400 créditos

| Momento | Frase |
|---|---|
| El taller entero | El vino de Navarra se guardaba en toneles y barricas de madera de roble. El tonelero las hacía sin clavos ni pegamento: solo madera doblada y aros de hierro. |
| Herramienta | Duelas. Tablas de roble curvadas. |
| Herramienta | Aros de hierro. Aprietan las duelas. |
| Herramienta | Fuego. Para doblar la madera. |
| Paso 1 | Una barrica se arma poco a poco. Ordena el trabajo. |
| Paso 2 | Los aros de hierro se bajan a golpes para que las duelas queden bien apretadas. |

## El cestero (Elizondo), unos 450 créditos

| Momento | Frase |
|---|---|
| El taller entero | En los caseríos hacían falta cestas para todo: manzanas, patatas, hierba o ropa. El cestero las tejía con tiras de madera de castaño o de avellano. ¡Las cestas de la pelota, la xistera, también se tejen a mano! |
| Herramienta | Cuchillo. Para abrir las varas en tiras. |
| Herramienta | Tiras de madera. Finas y flexibles. |
| Herramienta | Mazo. Para apretar el tejido. |
| Paso 1 | La madera seca no se dobla: primero hay que prepararla. Ordena el trabajo. |
| Paso 2 | Las tiras se pasan por encima y por debajo, una y otra vez, apretando bien. |
