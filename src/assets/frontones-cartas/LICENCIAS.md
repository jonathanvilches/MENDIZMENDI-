# Frontones de las tarjetas de campeonato

Cada imagen es un frontón real de Navarra. Está pintada con Higgsfield, modelo GPT Image 2.6, a partir de una foto de Wikimedia Commons, con la misma arquitectura y el mismo encuadre. Se han quitado personas, coches, carteles y textos y se ha cambiado la luz. Tamaño: 800 × 603 px, WebP.

El autor del proyecto aprobó el 13 de noviembre de 2026 usar fotos CC BY-SA como referencia, con crédito a cada autor. Las imágenes pintadas a partir de una foto CC BY-SA se comparten con la misma licencia, CC BY-SA 4.0.
